# 翻译服务商调研

> 调研时间：2026-09-04。价格、免费额度、接口规范**随时可能变动**，接入前务必到各官网核对最新政策。

## 选型结论（先说答案）

1. **免费层主力：腾讯云机器翻译 TMT** —— 每月 500 万字符免费额度，个人开发者可申请，量级远超同行，够撑起「基础功能免费」的承诺。
2. **备用引擎：百度翻译开放平台** —— 接入最简单（MD5 签名），但 QPS=1 限制严格，作为切换/对比用的第二引擎。
3. **AI 层（BYOK 直连）：DeepSeek / GLM / 通义 / Kimi** —— 全部兼容 OpenAI Chat Completions 格式，一套 Adapter 代码全接入，用户自带 Key，零成本。
4. **备选观察：Azure Translator** —— 免费额度不错，但国内连通性和账号门槛需实测后再定。

## 一、传统机器翻译引擎

### 1. 腾讯云机器翻译（TMT）—— 推荐主力

- **免费额度：** 每月 500 万字符文本翻译免费，超出后按字符阶梯计费（约 58 元/百万字符起，量越大越便宜）
- **接入流程：** 注册腾讯云 → 开通机器翻译 → 创建密钥（SecretId + SecretKey）→ 调用 `tmt.tencentcloudapi.com`
- **签名方式：** TC3-HMAC-SHA256 签名（V3 版接口），需在端侧实现签名算法，是接入的主要工作量
- **文本翻译 API：** `TextTranslate`，参数：`SourceText`、`Source`、`Target`、`ProjectId`
- **语言支持：** 中英日韩法德西俄等 30+ 语言，自动检测语言有单独接口
- **优点：** 免费额度断层式领先；大厂稳定；文档全
- **注意：** 个人实名认证后即可用；500 万字符额度如被刷爆，超出部分**直接产生账单**，App 内必须做限流

### 2. 百度翻译开放平台 —— 推荐备用

- **免费额度：** 标准版免费（不限月字符量），但 **QPS 限制 = 1**（每秒 1 次请求）
- **接入流程：** 注册 → 实名 → 开通「通用文本翻译」→ 拿到 AppID + 密钥
- **签名方式：** MD5（拼接 AppID + 随机数 + 密钥），实现简单
- **API：** `fanyi-api.baidu.com/api/trans/vip/translate`，GET/POST 均可
- **语言支持：** 20+ 主流语言
- **优点：** 免费不限量（在 QPS 内），接入最简单，适合做第二引擎
- **注意：** QPS=1 意味着连续快速翻译会报错（error code 54003），需要请求队列 + 间隔控制

### 3. Azure Translator（微软）—— 备选

- **免费额度：** F0 层每月 200 万字符免费，超出约 $10/百万字符
- **签名方式：** Ocp-Apim-Subscription-Key 请求头，接入简单
- **语言支持：** 100+ 语言，覆盖最广
- **注意：** 需 Azure 账号 + 创建 Translator 资源，国内网络连通性需实测；适合作为「长尾语言」补充引擎

### 4. 其他观察名单（暂不接入）

- **火山引擎机器翻译：** 有免费额度，字节系；接入难度与腾讯云相当
- **有道智云 / 小牛翻译：** 免费额度小或有偿，性价比不如前两家，暂不选

## 二、AI 大模型（BYOK 模式，用户自带 Key）

全部使用 OpenAI Chat Completions 兼容接口，`TranslatorAdapter` 只需实现一份：

| 模型 | Base URL | 备注 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com` | 便宜、中译英质量口碑好 |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | 国内访问稳定 |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | 阿里系 |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | 长文本强 |
| OpenAI / Claude 等 | 各自官方 | 需用户自行解决网络环境 |

**翻译 Prompt 模板（初版）：**

```
你是一位专业翻译。请将下面的{源语言}文本翻译成{目标语言}。
要求：
- 只输出译文本身，不要任何解释、前缀或引号
- 保持原文的语气、格式（换行、列表）与专有名词
- {风格指令：标准 / 更地道自然 / 正式书面 / 口语化}

待翻译文本：
{text}
```

- 普通翻译不需要 CoT，直接输出，减少 token 消耗和延迟
- 「润色/解释语法」模式放开输出格式，配合流式渲染

## 三、成本测算（免费层能撑多少用户）

以腾讯云 500 万字符/月估算，假设单次翻译 100 字符：

| 场景 | 单用户月用量 | 可支撑用户数 |
|---|---|---|
| 轻度（每天 5 次） | ~1.5 万字符 | ~330 人 |
| 重度（每天 50 次） | ~15 万字符 | ~33 人 |

**结论：** 免费额度大约能撑「几百个轻度用户」，早期完全够用；被脚本刷量是最大风险，必须做设备级限流（详见 README 风险表）。BYOK 用户不消耗自有额度。

## 四、合规与上架注意

1. **隐私声明：** 译文会传输到第三方引擎服务器（腾讯云/百度/用户自选大模型），隐私政策中必须明示，商店审核会查。
2. **个人开发者账号：** 使用他人 API Key 需要 App 内妥善加密存储（Asset Store Kit），不能明文存 Preferences。
3. **备案：** App 直连第三方 API、无自有服务器时，通常不涉及 ICP 备案；一旦自建代理服务器（内置 AI 额度模式）就需要备案 + 更严审核，这是初期只做 BYOK 的原因之一。
4. **引擎协议：** 逐家阅读服务条款，确认「客户端直连 + 商用 App」是否被允许；如有争议，走自家轻代理。

## 五、语言代码映射

各家语言代码不统一（腾讯 `zh`、百度 `zh`、Azure `zh-Hans`、大模型用自然语言），领域层统一用内部枚举（如 BCP-47 风格），各 Adapter 负责自家映射，UI 层绝不出现各家原始代码。
